Check Both Safari Location Permissions

  1. In iPhone Settings → Privacy & Security → Location Services:
    Turn Location Services on.
    For Safari Websites, allow access while using the app.
  2. In Safari, open the page menu → Website Settings → Location.
    Allow location for this website, not just for other websites.
  3. Return to this Safari tab and press the button again.
    If the denial persists, reload this page after changing permissions.
    If the PC has stopped accepting, restart it and scan its new QR code.

Permission settings are separate.
A new Cloudflare URL is a different website and may ask again.
